# **App Name**: GleamGenie Cleaning

## Core Features:

- Service Display: Showcase cleaning services with icons and descriptions.
- Pricing Plans: Display clean and simple pricing plans.
- WhatsApp Integration: Integrate a floating WhatsApp button for easy contact.
- Testimonials: Showcase customer testimonials with profile icons.
- Contact Form: Implement a contact form for inquiries.

## Style Guidelines:

- Primary color: Blue (#4682B4) to evoke trust and cleanliness.
- Background color: Creamy white (#FAF9F6) for a fresh and hygienic feel.
- Accent color: Beige (#F5F5DC) to complement the blue and creamy white tones.
- Body and headline font: 'Inter' sans-serif for a simple, easy-to-read design.
- Use cleaning-themed icons for services.
- Clean and minimal layout with lots of white space and rounded corners.
- Subtle shadow effects for depth and friendly look.
